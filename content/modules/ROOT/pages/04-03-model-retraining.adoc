== 소개

YOLO 모델을 재학습시키기 위해서는 **보통 수준 및 심각한 사고** 레이블이 포함된 자동차 이미지 데이터셋이 필요합니다.  
우리는 이를 위해 주석이 달린 이미지와 학습/검증 세트로 분할된 데이터셋을 준비해두었습니다.  
이 데이터셋은 https://universe.roboflow.com/accident-detection-ffdrf/accident-detection-8dvh5/dataset/1[RoboFlow,window=_blank] 에서 확인할 수 있습니다.

[%collapsible]
====

2. 데이터셋은 `data`라는 폴더 안에 `train`과 `valid`라는 두 하위 폴더로 나뉘어 있고,  
   각각의 폴더 안에는 `images`와 `labels`라는 하위 폴더가 존재합니다.  
3. 각 이미지와 동일한 이름의 주석 텍스트 파일이 `labels` 폴더에 존재하며, 객체 인식에 필요한 정보가 담겨 있습니다.

== 모델 재학습 결과 해석
[%collapsible]
====
다음은 전체 데이터셋을 사용한 학습 결과 예시입니다.

먼저 'epoch' 개념을 이해해봅시다.  
머신러닝에서는 전체 학습 데이터를 모델에 한 번 통과시키는 것을 **1 epoch**라고 부릅니다.  
즉, 1 epoch는 전체 데이터셋이 한 번 학습 알고리즘을 통과한 것을 의미합니다.

아래 예시에서는 총 7 epoch 동안 학습을 수행했으며, 한 번에 32개의 이미지를 처리하도록 **batch size**를 32로 설정했습니다:  
```python
results = model.train(data='./datasets/accident-full/data.yaml', epochs=7, imgsz=640, batch=32)
```

학습 실행 중에는 각 epoch마다 **학습 단계**와 **검증 단계**의 요약 결과가 표시됩니다.  
- 1~2번째 줄은 학습 단계 결과를 보여주며,  
- 3~4번째 줄은 검증 단계 결과를 보여줍니다.

image::04/model-retraining-summary.png[retraining summary]

학습 단계에서는 **손실 함수(loss function)**를 기반으로 오류를 계산하며, 여기서 가장 중요한 지표는 `box_loss`와 `cls_loss`입니다:

* `box_loss`: 모델이 예측한 **경계 상자(bounding box)**의 오류 정도를 나타냅니다.  
* `cls_loss`: 모델이 예측한 **객체 분류(classification)**의 오류 정도를 나타냅니다.

모델이 데이터를 기반으로 학습을 제대로 하고 있다면, 이 두 값은 **epoch가 진행될수록 점점 감소**해야 합니다.  
이전 스크린샷 예시에서는:
- `box_loss`: 1.219 (1번째 epoch) → 0.8386 (마지막 epoch)로 감소했고,
- `cls_loss`: 1.875 → 0.9001로 감소했습니다.

또 다른 중요한 품질 지표는 **mAP50-95** (Mean Average Precision)입니다.  
모델이 잘 학습될수록 정확도(precision)는 점점 증가해야 합니다.  
예시에서는 `mAP50-95`가 0.423 (1번째 epoch) → 0.755 (7번째 epoch)로 증가했습니다.

또한 학습 과정 전체에서 **GPU가 사용되었으며**, 약 13GB 이상의 GPU 메모리가 소모된 것도 확인할 수 있습니다.

만약 마지막 epoch 이후에도 충분한 정확도를 얻지 못했다면:
- **epoch 수를 늘리거나**,  
- `batch`, `lr0`, `lrf` 등의 파라미터를 조정하거나,  
- **optimizer를 변경**해서 다시 학습을 시도할 수 있습니다.

모델은 학습 도중에 매 epoch마다 다음 경로에 저장됩니다:
- `/runs/detect/train/weights/last.pt`: 마지막 epoch에서 학습된 모델
- `/runs/detect/train/weights/best.pt`: **가장 높은 정확도를 기록한 모델**

→ 학습이 완료되면 일반적으로 **`best.pt` 파일을 실 운영 환경(production)에 사용**하게 됩니다.

**참고:** 실제 프로젝트에서는 훨씬 더 많은 epoch를 수행해야 하며, 학습 완료까지 **수 시간 또는 수 일이 걸릴 수 있습니다.**  
이 예시처럼 단 16분 만에 끝나는 경우는 드물다는 점을 염두에 두세요.
