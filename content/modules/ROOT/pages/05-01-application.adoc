= 애플리케이션 개요
include::_attributes.adoc[]

이제 우리가 **3. LLM 활용 실습**, **4. 이미지 처리 및 모델 서빙** 단계에서 테스트했던 기능들을 활용하는 샘플 웹 애플리케이션을 배포해보겠습니다.  
애플리케이션의 구조와 코드는 아래 내용을 통해 확인하실 수 있습니다.  

== 아키텍처

다음은 이 애플리케이션의 간단한 아키텍처 다이어그램입니다:

[.bordershadow]
image::05/application-architecture.drawio.svg[]

구성 요소는 다음과 같습니다:

- **프론트엔드**: 사용자의 브라우저에서 실행되는 애플리케이션 자체입니다.  
  Patternfly 프레임워크(React, Typescript)로 개발되었습니다.

- **백엔드**: Python 기반의 FastAPI 애플리케이션이며, {ocp} 환경의 컨테이너에서 실행됩니다.  
  데이터베이스, LLM, 오브젝트 스토리지와 통신하며, 프론트엔드와는 REST API를 통해 데이터를 주고받습니다.

- **데이터베이스**: PostgreSQL 데이터베이스이며, {ocp} 컨테이너에서 실행됩니다.  
  청구(claim) 데이터를 저장합니다.

- **LLM**: 청구서로부터 요약과 정보 추출을 수행하고, 챗봇 기능을 담당하는 언어 모델입니다.  
  백엔드에서 API를 통해 호출합니다.

- **벡터 DB(VectorDB)**: 문서를 임베딩 형태로 저장하고 검색할 수 있도록 해주는 벡터 데이터베이스입니다.  
  Milvus를 기반으로 합니다.

- **오브젝트 스토리지**: S3 호환 오브젝트 스토리지이며, 청구 이미지들을 저장합니다.
