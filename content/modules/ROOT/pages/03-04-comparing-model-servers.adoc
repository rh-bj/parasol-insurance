지금까지 이 {ic-lab}에서는 https://huggingface.co/ibm-granite/granite-7b-instruct[Granite 7B Instruct,window=_blank] 모델을 사용해 왔습니다.  
이 모델은 다른 모델들에 비해 가볍긴 하지만 여전히 리소스 요구량이 높으며, 실행을 위해서는 대형 GPU가 필요합니다.  
그렇다면, CPU만으로 실행 가능한 더 작은 모델을 사용해도 비슷한 결과를 얻을 수 있을까요? 직접 확인해봅시다!

이번 실습에서는 이전에 사용한 모델과 훨씬 작은 LLM인 https://huggingface.co/google/flan-t5-large[flan-t5-large,window=_blank] 모델을 비교해봅니다.  
두 모델의 결과를 비교하여, 작은 모델이 우리의 사용 사례에 적합한지를 확인해보겠습니다.
