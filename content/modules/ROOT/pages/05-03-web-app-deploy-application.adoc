= GitOps를 통한 애플리케이션 배포
include::_attributes.adoc[]

우리가 배포할 애플리케이션은 이전 섹션에서 확인하셨던 것처럼 프론트엔드, 백엔드, 청구 데이터 DB, LLM, 벡터 DB, 오브젝트 스토리지 등으로 구성되어 있습니다.  

이 중 LLM과 벡터 DB, 오브젝트 스토리지는 클러스터 전체에 공유되는 것을 유저들이 함께 사용하며,  
여러분 각자의 프로젝트에 프론드엔드 및 백엔드 앱, 청구 데이터 DB를 배포해보겠습니다.  

== GitOps로 애플리케이션 배포하기

우리는 OpenShift GitOps / {argocd}를 활용하여, 애플리케이션을 여러분의 네임스페이스에 한번에 배포할 것입니다.

- 우측 상단 메뉴에서 {argocd} 콘솔 링크를 클릭해 접속하세요.
+
[.bordershadow]
image::05/05-open-argocd.png[]

- "Log in via OpenShift" 버튼을 클릭해 OpenShift 계정으로 로그인합니다.
+
[IMPORTANT]
====
로그인 하실 유저 이름은 `{user}` 입니다. 
====

[.bordershadow]
image::05/05-login-argocd-openshift.png[]
+
[.bordershadow]
image::05/05-openshift-login.png[]

- 로그인 후 {argocd} 콘솔로 이동되며, "Applications" 탭에서 **"Create Application"** 버튼을 클릭하세요.
+
[.bordershadow]
image::05/05-create-application.png[]

- 열린 창 우측 상단에서 **"Edit as YAML"** 버튼을 클릭합니다.
+
[.bordershadow]
image::05/05-edit-as-yaml.png[]

- 아래의 YAML 내용을 복사하여 편집기에 붙여넣고, 기존 내용을 대체한 후 **"Save"** 를 클릭하세요:
+
[source, yaml, subs="attributes+"]
----
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: claim-insurance-app-{user}
spec:
  destination:
    server: https://kubernetes.default.svc
    namespace: {user}
  project: project-{user}
  source:
    path: lab-materials/05/app
    repoURL: https://github.com/rh-aiservices-bu/parasol-insurance.git
    targetRevision: main-rhoai-2.13
  syncPolicy:
    automated:
      prune: true
      selfHeal: false
    syncOptions: [CreateNamespace=false]
----
+
[.bordershadow]
image::05/05-application-yaml-save.png[]

- 다시 폼 화면으로 돌아오면 **"Create"** 버튼을 클릭하세요.
+
[.bordershadow]
image::05/05-create-application-validation.png[]

- 애플리케이션 배포가 시작됩니다.  
카드를 클릭하면 배포 상태의 상세 정보를 확인할 수 있습니다.
+
[.bordershadow]
image::05/05-application-creation.png[]

- 잠시 후 모든 구성요소가 배포되면, 애플리케이션 상태는 **"Healthy"** 및 **"Synced"** 로 표시됩니다.
+
[.bordershadow]
image::05/05-application-deployed.png[]

- 이제 다음 URL을 통해 애플리케이션에 접근할 수 있습니다:  
  https://ic-app-{user}.{openshift_cluster_ingress_domain}/[https://ic-app-{user}.{openshift_cluster_ingress_domain}/,window=_blank]

브라우저에서 위 주소를 열어 애플리케이션을 확인해보세요.  
그리고 다음 단계로 진행합니다.
