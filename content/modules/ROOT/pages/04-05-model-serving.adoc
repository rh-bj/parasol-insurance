image::04/04-add-data-connection.png[]

* 다음 정보를 입력하세요:

** Name:

[.console-input]
[source, text]
[subs=attributes+]
Shared Minio - model
** Access Key:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
{minio-user}
** Secret Key:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
{minio-pass}
** Endpoint:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
{minio-endpoint}
** Region:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
none
** Bucket:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
models

* 아래와 같은 결과 화면이 나타나야 합니다:

== 모델 서버 생성하기

프로젝트 내에서 **Models** 탭으로 이동하여 모델 서버를 생성하세요.

**매우 중요**: 아래 단계에서 **올바른 유형의 모델 서버**를 선택해야 합니다. 잘못 선택하면 프로젝트를 초기화해야 할 수 있습니다.

* 오른쪽에 있는 **Multi-model serving platform** 유형을 선택한 후 **Add model server**를 클릭합니다:
+
[.bordershadow]
image::04/add-model-server.png[]

* 아래 정보를 입력하세요:

** Model server name:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
My first Model Server
** Serving runtime:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
OpenVINO Model Server
** Number of model server replicas to deploy:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
1
** Model server size
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
Standard
** Accelerator
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
None (버그: 실제로는 `None`을 선택해도 드롭다운엔 `Select...` 로 표시됩니다.)
** Model route
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
unchecked
** Token authorization
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
unchecked

* 설정이 완료되면 다음과 같은 화면이 표시됩니다:
+
[.bordershadow]
image::04/add-model-server-config.png[]

* **Add** 버튼을 눌러 모델 서버를 생성하세요.

프로젝트 내 **Models** 탭으로 이동한 후 **Models and model servers** 항목에서:

* **Deploy model** 버튼을 클릭합니다:
+
[.bordershadow]
image::04/select-deploy-model.png[]

* 다음 정보를 입력하세요:

** Model name:
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
My first Model
** Model server
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
My first Model Server (자동 입력됨)
** Model server - Model framework
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
onnx-1
** Existing data connection - Name
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]
Shared Minio - model
** Existing data connection - Path
[.lines_space]
[.console-input]
[source, text]
[subs=attributes+]

* 다음과 같은 화면이 나타납니다:
+
[.bordershadow]
image::04/deploy-a-model.png[]

* **Deploy** 버튼을 클릭합니다.

* 모델이 정상적으로 배포되면, 약 15~30초 후 상태가 초록색(green)으로 표시됩니다.
+
[.bordershadow]
image::04/model-deployed-success.png[]

이제 모델이 실제로 동작하는지 확인하기 위해 쿼리를 날려보겠습니다!

== 배포된 모델 쿼리하기

모델이 서빙되면, 엔드포인트 형태로 접근할 수 있게 됩니다.  
이제 모델에게 요청을 보내고, 응답을 받아보겠습니다.  
이 방식은 앞서 노트북에서 실습했던 것과 달리, **클러스터 내 모든 사용자 또는 애플리케이션**에서도 접근 가능한 방식입니다.

* 먼저, 모델 서버의 URL을 알아야 합니다.
* **Inference endpoint** 열 아래의 **Internal Service** 링크를 클릭합니다.
* 팝업 창에서 모델 서버에 대한 여러 URL이 표시됩니다:
+
[.bordershadow]
image::04/inference-url.png[]

* 이 중 **RestUrl**을 메모하거나 복사하세요. 예: `http://modelmesh-serving.{user}:8008`

이제 이 URL을 사용해 모델에 쿼리를 보내보겠습니다.
