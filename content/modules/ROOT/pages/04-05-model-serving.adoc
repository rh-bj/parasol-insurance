= 모델 서빙
include::_attributes.adoc[]

`4.1`~`4.4` 단계에서는 이미지 인식 모델(yolov8m)을 노트북에 다운로드하거나 로컬에서 로드하여 사용했습니다.
이제 모델을 이 노트북 환경에서 직접 실행하는 것이 아니라, URL을 통해 노트북 외부의 모델 서버에 요청을 보내고 응답을 받을 수 있도록 모델을 서빙해보도록 하겠습니다.

먼저, 배포할 모델이 저장되어 있는 S3 오브젝트 스토리지의 정보를 `Data Connection` 을 통해 나의 OpenShift AI 프로젝트에 등록합니다.  
그리고 동일한 OpenShift AI 프로젝트에서 모델을 실행할 적절한 추론 엔진(Serving runtime)을 선택하여 모델 서버를 생성합니다.  
마지막으로 S3 오브젝트 스토리지에 저장되어 있는 모델의 주소를 입력하여 모델 서버에 배포해보는 순서로 진행됩니다.  

== 실습 단계
. 이제 모델을 {rhoai-short}의 모델 서빙(Model Serving)에 배포해야 합니다.
. 새로운 데이터 연결(Data Connection)을 생성합니다.
.. 버킷 이름은 `models` 로 설정합니다.

== 배포된 모델 쿼리하기

모델이 서빙되면, 엔드포인트 형태로 접근할 수 있게 됩니다.  
이제 모델에게 요청을 보내고, 응답을 받아보겠습니다.  
이 방식은 앞서 노트북에서 실습했던 것과 달리, **클러스터 내 모든 사용자 또는 애플리케이션**에서도 접근 가능한 방식입니다.

* 먼저, 모델 서버의 URL을 알아야 합니다.
* **Inference endpoint** 열 아래의 **Internal Service** 링크를 클릭합니다.
* 팝업 창에서 모델 서버에 대한 여러 URL이 표시됩니다:
+
[.bordershadow]
image::04/inference-url.png[]

* 이 중 **RestUrl**을 메모하거나 복사하세요. 예: `http://modelmesh-serving.{user}:8008`

이제 이 URL을 사용해 모델에 쿼리를 보내보겠습니다.
